# Profilul profesional al managerului școlar

Versiune GitHub Pages cu un singur fișier principal `index.html`.
Nu depinde de foldere CSS/JS externe, astfel încât este mai robustă la încărcarea pe GitHub.

## Publicare
1. Descarcă arhiva ZIP și DEZARHIVEAZ-O pe calculator.
2. Creează repository-ul GitHub.
3. Încarcă în rădăcina repository-ului cele 3 fișiere: `index.html`, `.nojekyll`, `README.md`.
4. Commit changes.
5. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

IMPORTANT: nu încărca arhiva ZIP ca atare; GitHub Pages nu o dezarhivează.
